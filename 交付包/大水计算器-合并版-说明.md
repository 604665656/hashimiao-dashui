# 大水计算器 · 合并版

> 弱者喝饮料，强者喝大水。
> 一个 HTML 拷走就能玩：桌宠仪表盘 + 哈士喵剧情剧场 + 多个可选虚拟形象，零 CDN、零依赖、数据只存本机。

## 要解决什么

之前是两个独立文件：

- `大水计算器.html` —— 桌宠仪表盘版（进度环、周图、提醒、语录、奶茶抓拍、日报、积分双榜、打卡分享、定位）
- `大水计算器-哈士喵AVG.html` —— 剧情互动版（哈士喵监察司、6 种结局、CG 图鉴、存档）

两个文件两套数据键，喝水记录在仪表盘、剧情又是另一本账；想换个形象也没有入口。所以这轮合成**一个文件、一份数据、两种视图**，并把「虚拟形象」做成可切换的选项。四轮生图排期产出的美术也一并内嵌落地，不再只是躺在文件夹里的 PNG。

## 怎么做的

### 一个文件，一份数据

以桌宠版为底座（功能最全），把 AVG 版的**哈士喵现成素材**（背景 10 / 立绘 8 差分 / 情境 CG 8）和**四轮生成的 28 张新美术**（分享卡主视觉 2、拦截 CG 1、心情图标 6、荣誉横幅 1 + 徽章 6、水滴状态 6、Rank 徽章 6）全部转成 WebP data URI 内嵌。合计 **54 张内嵌位图**，成品 **734 KiB**，仍是单文件、离线可玩。

数据沿用桌宠版的 `dashui.pet.v1`，旧桌宠记录自动带过来。启动时做一次**AVG 旧存档安全合并**：把 `dashui.avg.v1` 里的饮水流水、结局解锁、CG 解锁只补不覆盖地并进来，打标记防重复。

### 多个可选虚拟形象

主面板「今日打卡」卡片下有一行 chips，设置里也有一份；点桌宠循环切换，双击随机换。

| 形象 | 外观 | 口吻 |
|---|---|---|
| 💧 大水滴 | 原内联 SVG，水位本身就是今日进度条 | 大水监察司 · 水滴 |
| 🐱 哈士喵 | 现成 8 差分立绘，按心情自动换表情 | 首席监察喵，句尾带「喵」 |
| 🫧 小水滴酱 | 第 4 轮生成的 5 状态差分，按完成度/奶茶记录换图 | 见习监察，软萌 |
| 🎲 每日轮换 | 按日期哈希在以上三者里挑一个，气泡写明当天是谁 | 今日当值形象 |

切换会同步改变：桌宠外观、气泡署名、剧情序章里的称呼、结算与拦截台词的口吻。形象选择存进本机，刷新不丢。

### 两种视图

- **仪表盘**：原来的全部功能，一个没砍。
- **🎬 剧情互动**：全屏剧场层，序章 → 宣誓 → 枢纽循环 → 结算 → 6 种 Rank 结局。枢纽里能吨一口 / 整瓶灌 / 生成语录 / 心情登记 / 奶茶自首 / 结算 / 看排行榜 / 回仪表盘。**剧场和仪表盘共用同一本监察本**：在剧场喝的水立刻出现在仪表盘进度环，冷却期内照样被哈士喵按住瓶盖。

### 美术落地位置

## 坑

1. **两个 script 段的加载顺序**：剧情层代码放在第二个 `<script>`，若在第一个 script 的 `renderAll()` 里直接调 `renderAvatar()`，初始化时会报 `ReferenceError`。改成在第二个 script 里包装 `renderAll = function(){ base(); renderAvatar(); }`，再主动跑一次。
2. **Canvas 同步绘制与 data URI 解码**：`drawShareCard()` 是同步返回 PNG，现场 `new Image()` 往往还没解码完，画出来只剩渐变底。改成页面启动时预热 `SHARE_IMG` / `AUX_IMG` / `MOOD_IMG`，并保留渐变兜底。
3. **设置面板是动态生成的**：一开始给 `#setAvatars` 直接绑事件会抛错并中断整段脚本。改成 `document` 事件委托 + 面板 HTML 内联 chips。
4. **立绘被对话框盖住**：枢纽有 8 个选项，对话框撑到 56vh，`bottom:270px` 的立绘只露出猫耳。改成 `bottom:calc(58vh + 8px)`，桌面和手机都完整露出。
5. **结局判定参数错位**：初版把 goal 和 milk 都写成了同一个参数 `s`，达标判定会永远算错。改成 `cond(ml, goal, milk)` 三参数并按数组顺序 `find`。
6. **测试断言误报（两次）**：`每日轮换` 当天恰好解析成「大水滴」却被断言要求必须显示图片；拦截台词在读文本时打字机才打了几个字就被判为「失效」。都是测试写得不够严谨，不是产品缺陷——改成按当天解析结果断言、先跳过打字机再读全文。
7. **窄屏回归被定位弹窗挡住**：测试关掉定位权限后自动弹三级选择器，`mask` 拦截了按钮点击。测试改用有定位权限的上下文；产品本身降级逻辑正常。

## 文件与隐私

- 主文件：`大水计算器-合并版.html`，双击即可玩；想让定位 / 摄像头 / 系统通知都正常，建议在该目录跑 `python3 -m http.server 8000` 再访问 `http://localhost:8000/大水计算器-合并版.html`。
- 旧两版仍保留作备份，数据键各自独立（`dashui.pet.v1` / `dashui.avg.v1`），不会互相覆盖；以后只用合并版即可。
- 照片、饮水记录、心情、位置、档案与成绩、形象选择、剧情解锁、分享校验码全部存在浏览器 `localStorage`，**不上传**。清浏览器数据会一并清掉，重要记录用「导出数据」备份 JSON。
- 在线大模型为可选项，不填就完全不发外部请求；天气请求只发往 Open-Meteo。
- 排行榜是本机多档案，不是联网榜单；校验码只用于本机核对。
- 「大水理论」是网络梗，不是医学结论。目标量参考《中国居民膳食指南(2022)》：温和气候低活动量成人男 1700ml / 女 1500ml；单次 >500ml 或 1 小时 >1000ml 会提醒「别猛灌」。

# 音频专项增补（同四小节）

## 要解决什么

原来桌宠版只有一个 `beep()` 正弦提示音，AVG 版有 4 段内嵌 ogg 和 BGM，但两版合并后 AVG 那段音频没跟过来；而且两版旧设置都是 `sound:true / bgm:true`，打开就出声。这轮要做的是：**音效与音乐都要有，但默认全部关闭**，用户能自己开、能调音量、能选曲、能逐个试听。

## 怎么做的

- 从 AVG 版取出 4 段现成 ogg（轻快 / 安静 / 揭晓 / tick），内嵌进合并版，不新增外部文件。
- 音效引擎分两层：现成 ogg 用于 BGM 与「揭晓」；Web Audio 现场合成 5 种短音（打卡叮咚 / 防作弊拦截 / 语录风铃 / 奶茶快门噪声 / 形象切换），零额外体积。
- `sfx(k)` 双门槛：开关没开不响、用户还没发生过第一次点击也不响（绕开浏览器自动播放限制）；「音效试听」用 `force=true` 单独放行，只响一次。
- `bgm(name)` 单实例管理，关闭时 `pause()` 并清空引用，不会越切越多；剧场开场自动起曲、结局自动切「揭晓」。
- 新增 **🎛 音效与音乐** 独立面板：主视觉横幅 + 6 枚音效图标 + 两枚大开关 + 音量条 + 3 首曲目 + 6 个试听按钮；主面板有入口，设置面板里有 BGM 开关和面板入口，剧场 HUD 有 🔇/🔕 两个快捷按钮。
- 生图补了 2 张：1:1 六格音效图标集（切出 6 张单图）+ 16:9 戴耳机哈士喵音乐主视觉，全部转 WebP 内嵌。
- 老存档一次性迁移：`dashui.audio.defaultOff` 标记，把历史里开着的 `sound/bgm` 也重置为关，音量默认 0.35，曲目默认「轻快」。

## 验证

无头浏览器回归 **0 发现项、0 控制台错误**，覆盖：全新用户与老存档都是默认关且加载时不自动播放、面板 7 张内嵌图全解码、开关/音量/曲目/6 个试听、刷新持久化、关闭 BGM 后 `audioEl` 与 `curBgm` 清空、仪表盘 5 类音效钩子（形象 / 喝水 / 拦截 / 语录 / 自首）、剧场开场与结局 BGM、音乐关时结局不偷偷播、剧场 HUD 图标同步、375px 音频面板无溢出，以及原有 4 形象 / 防作弊 / 分享卡 / 双榜 / 设置 / 剧情层的回归。

## 坑

1. **锚点写死缩进踩空**：升级脚本按 `renderMoods(); renderAvatar();` 带 8 空格缩进去找 `stMood` 里的心情写入，实际那行在箭头函数里、缩进不同，命中 0 次导致整段升级回滚。改成按不含前导空格的核心串匹配后通过。
2. **试听断言多算了两次**：`end` 内部走 `playClip('揭晓')`、`bgm` 走 `playClip(曲目)`，被测试包装器二次记录，初版按「恰好 6 次」断言误报。改成按音效 kind 集合 + 至少一个 clip 调用来判。
3. **奶茶自首会弹模态挡住后续点击**：`#btnSin` 按钮真实 id 不是 `#btnMilk`；自首后通知书弹层不关，后面点「剧情互动」会被 `mask` 拦截超时。测试里改成先关 `#nClose`。
4. **结局 BGM 断言与用例状态不符**：初版只开了音效没开音乐，却要求结局切「揭晓」曲，误报一次。改成用例里同时开 BGM，并补一条「音乐关时结局不自动播放」的反向断言。
5. **生图水印**：两张图的水印都落在格子外纯米白背景上，沿用「低饱和灰色笔画检测 + inpaint」一次清干净；音乐横幅选中 2.2 万笔画像素，比图标集多，但没碰到边框和角色。第三张计划里的「音效默认策略图」没有可靠数据支撑，最终没做，避免把「资料未核实」画成「默认关闭」。

# Toy 上架适配层增补（同四小节）

## 要解决什么

调研报告初版把「纯本地单文件」当成唯一形态，把云存档与跨用户榜判成「不成立」。但本项目在 **B站 Toy** 上架，平台本身提供云存储与分数能力——由平台提供、不是自建后端，所以结论要按形态分叉。目标一句话：**同一个 HTML，本地双击完全离线可玩；放进 Toy 容器自动获得云存档与平台榜，且敏感数据永不上云。**

## 怎么做的

- 第三个 `<script>` 里加能力探测：`window.toy / studio.sdk.toy / ToySDK / bl` 四种形态按 duck typing 找，`available()` 与 `ready()` 带超时（1200+800ms）和一次短重试；探测不到或超时就 `mode='local' / 'degraded'`，完全静默。
- 存档抽象成 `Store` 思路：`save()` 包装成排队（防抖 8 秒），`submitDay()` 结算时立即同步并 `rank.submit({score, extra:{at, rule:2}})`；`pagehide` / 页面隐藏时补一次 flush。
- 云档只放**白名单最小可重建摘要**（schema 2）：每日水量 / 有效打卡 / 拦截 / 奶茶 / 审计哈希头、积分与结算成绩、达标时刻、Rank / CG 解锁 id、形象与心情枚举、设置项、水合指数、校验和。按 UTF-8 字节切成 ≤900 B 的分片（`ds_meta` + `ds_0…`），兼容 `cloud.set/get` 与 `bl.setUserCloudStorage` 两种写入形态。
- **永不上云**：抓拍照片、完整流水、在线模型 API Key / endpoint、精确 GPS、通知 / 摄像头授权状态、完整语录上下文。用「只查键名不查值」的 `toySensitiveAudit()` 拦截（避免用户档案名叫 `latte` 被误判）。
- 读档：先本地、再云；空档 / 校验失败 / 超时一律保留本地并标「云端暂无可用存档」；两份版本不一致先**重读一次**，仍不同才弹「恢复向导」三选一（合并解锁取并集 / 用云端 / 用本机覆盖云端）。「用云端」只覆盖白名单摘要字段，本地 `logs / photo / llm / location` 一律保留。写入「结果未确认」不回写本地版本号，留待下次重读验证。
- 平台分数榜做成第三个 tab，只在 Toy 形态出现，且**需玩家点击授权**才参加；榜单缓存、只在结算时提交；界面明确写「客户端休闲成绩展示，非官方认证、无服务器反作弊」。本机档案榜始终保留。
- 主面板加一枚状态 chip（`💾 本地档案 / ☁ 云存档 / ⚠ 降级中`），点开是「存档状态」面板：形态、SDK 类型、云档校验和、上云白名单 / 不上云清单、单设备编辑提示、立即同步、参加平台榜、导出本机镜像。分享卡与文案按形态切一行说明。

## 验证

无头浏览器 **14 组用例全过，0 发现项、0 控制台错误**，三段脚本合并后按同一词法环境复查无重复声明。覆盖：本地形态零 SDK 零联网、Toy 探测与三 tab、结算分数提交、SDK 未就绪降级、未授权、写入超时后本机数据完好、损坏 / 空云档不覆盖、冲突重读与恢复向导三选一、云载荷敏感字段审计、体积与零外链、原有全链路（4 形象 / 防作弊 / 双榜 / 分享卡 / 音效默认关 / 剧场 / 刷新持久化）、375px 窄屏、Toy 跨会话、凌晨语录、平台榜↔本机榜切换无残留。

产物 **833.3 KiB**，适配层增量 **23.1 KiB**（方案预估 <20 KiB，偏差已如实留档），61 张内嵌 WebP + 4 段 ogg 不变，零 CDN、零外链、打包只有一个 `.html`。

## 坑

1. **事件处理器值拷贝**：`$('#btnBoard').onclick=openBoard` 绑定的是当时的函数值，重新赋值 `openBoard` 不生效。改包装 `bindBoard`＋重绑按钮引用＋capture 阶段截断原 `onclick`。
2. **无限微任务链**：`renderToyBoard` 里递归 `toyRankLoad().then(重绘)` 会把主线程占满、点击直接挂起。拆开拉取与渲染，只在用户手势处拉一次。
3. **敏感字段查值误判**：初版用正则扫 JSON 字符串，用户档案名含 `lat` / `key` 就会跳过云写入。改成只递归收集**键名**再比对白名单。
4. **测试 seed 被自动写覆盖**：页面空档分支 1.5 秒后自动写一份合法云档，冲掉预置的损坏 / 冲突档，造成两次误报。改成 `addInitScript` 同步预置 + Mock 冻结自动写。
5. **降级 5 秒太久**：SDK 未就绪原本要等 3000+2000ms，缩到 2 秒内完成，玩法不中断。
6. **平台榜 UI 残留**：第三 tab 下还显示「新增本机选手」输入框，副标题仍写「数据不上传」。改成切 tab 时隐藏控件 / 换副标题，切回本机榜再恢复。
7. **凌晨 0–6 点被当成清晨**（既有 bug，顺手修）：积分口径仍算 `dawn`，但语录会冒出「刚开机 / 天刚亮 / 太阳挺好」。加 `isDeepNight()` 按实际小时换夜间时间词、天气词、行动词与时段标签。
8. **成功读档残留旧提示**：云档读到后没清 `lastErr`，存档面板会同时显示「云存档」和「云端暂无可用存档」。补一行清空。

# P0 三条链路增补（同四小节）

## 要解决什么

竞品调研给的三条 P0 一直没落地：提醒还是「无条件每 30 分钟弹」，完成目标后照催、凌晨也照催；饮水记录是可直接改的累加器，改了 `localStorage` 也看不出来；留存储仍隐含「断签清零」的压迫感。这轮把三条链路一起补完，**不加任何新功能入口、不新增生图与音频**。

## 怎么做的

**① 智能提醒**：`reminderDecision(now)` 是纯函数，按 7:00–22:00 三段累计曲线（早 30% / 中 50% / 晚 20%）算「此刻应喝多少」，与实际水量比对。落后 ≥250ml 且距上次提醒够久才弹；达标即停催；22:00–07:00 免打扰（1 分钟演示模式豁免，否则看不到效果）；连续忽略 2 次只升级一次「🫧 温柔提醒」，不轰炸。设置里可选「智能 / 固定间隔」，另有「🎯 专注 30 分钟」延期，每天最多 3 次。用户明确的「别吵我」（专注、免打扰、达标）**两种模式都生效**。喝水打卡会清掉忽略累计。HUD 有一行实时说明「为什么现在提醒 / 不提醒」。

**② 审计流水**：统一 `appendLog(day, rec, source)`，每笔补 `seq / prevHash / hash / localDate / auditSource`，哈希是同步 FNV 链（payload 含 `prevHash`，改任意一笔必断链），`file://` 下也能跑、不把打卡改成异步。来源区分 `quick / manual / selfie / avg-migrate / legacy`。老存档在 `init()` 最前面一次性补链，**只加元数据、不动 `id/ts/ml/type/note/photo`**。链头写进分享卡文案、卡面和 Toy 云档（`auditHead / auditOK`），接收方可按同版本规则复核。冲突时不冻结档案、不静默覆盖，只在 HUD 标红提示导出核对。

**③ 可信水合指数**：0–100，与积分 / 榜单 / Rank 完全解耦。公式 = 今日完成度 55% + 打卡节奏 20% + 近 7 天均值 25%，新用户给 **15 分信任基线**（不是一打开就 0）。漏记只按空白时长缓慢回落（每小时 −2，上限 −12，夜间不计），奶茶 −3 / 连打 −2，都**不清零**。里程碑 60 / 80 / 95 各送 1 张 🎫 修复券，用券后一小时内抵消空白衰减。HUD 显示指数条、历史最高、券数、审计链状态。

**接入面**：设置面板多两项（提醒策略、专注延期）；分享文案 / 卡面 / 结算台 / 剧场结算 / Toy 云档都带指数与链头；`renderAll()` 与 15 秒定时器同步刷新新指标。产物仍是单文件、零 CDN，61 张内嵌 WebP + 4 段 ogg 不变。

## 验证

无头浏览器 **14 组用例全过，0 发现项、0 控制台错误**。覆盖：审计链写入与链式衔接、篡改检出且不覆盖原记录、老存档迁移原字段（含照片 base64）不变、自首 / AVG 迁移都带链、智能提醒 9 种决策（落后 / 跟得上 / 达标 / 深夜 / 凌晨 / 固定 / 专注 / 柔性 / 间隔不足）、提醒真的写入且喝水清零、指数不清零与轻扣、里程碑发券与修复券、券状态落盘与老存档首次静默补齐、分享卡 / 云档接入、设置保存与延期上限、Toy 双形态冒烟、原有全链路（4 形象 / 防作弊 / 双榜 / 音效默认关 / 剧场 / 凌晨语录 / 刷新持久化）、375px 窄屏、体积与零外链。

产物 **845.2 KiB**，增量 **11.9 KiB**（纯逻辑，无新增素材），零外部资源引用。

## 坑

1. **审计来源字段名撞车**：初版用 `source`，但自首记录里 `source` 已经是「照片来源」（camera / placeholder），会被覆盖掉语义。改名 `auditSource`，原始 `source` 一字段不动。
2. **修复券自我发券循环**：用券把指数抬高 → `hiSync()` 又判定跨过下一个里程碑 → 再发一张券，净消耗 0。拆出 `hiRaw()`（自然值）只用于里程碑判定，`hydrationIndex()` 只负责展示（含修复抬升）。
3. **券状态没落盘**：`hiSync()` 改了 `hiTickets / hiBest / hiAwards` 却没 `save()`，刷新就重复发券。改成「只在状态真的变化时 save」，避免 15 秒定时器反复写。
4. **老存档首次打开刷屏**：高指数老用户第一次运行会同时跨过 60/80/95，弹 3 个 toast、补发 3 张历史券。加 `hiAwardsInit` 标记，首次静默补齐已达里程碑，之后的跨越才发券。
5. **固定间隔模式绕过「别吵我」**：初版把 `focusUntil` / 免打扰检查放在 `if(mode==='fixed')` 之后，用户选固定间隔再点专注仍会被催。把专注 / 免打扰 / 达标停催提到模式分支之前，演示模式单独豁免免打扰。
6. **测试断言把清晨词当 bug**：凌晨回归里「刚开机 / 天刚亮」只在 `isDeepNight()` 为真时才算违和，早上 8 点说这些其实合理。改成非深夜直接跳过该断言，去掉日志噪音。
7. **窄屏首屏被挤爆**：新增两行指标后，375px 下「今日打卡」卡片只剩标题、冷却与指数全要滚动才看得到。压缩 `.hi-box` 内边距 / 行高 / 进度条高度并把脚注改成单行省略，指标卡从 73px 压到 **58px**，回归仍 0 溢出。
8. **`AT()` 差点写进浏览器上下文**：回归里的时间构造函数定义在 Node 侧，`page.evaluate` 里调用会 ReferenceError。挪进 evaluate 函数体，另修了一处 `==>` 手滑。

# P1 增补：数据可迁移 / 凭证 / 状态层（同四小节）

## 要解决什么

P0 三条链路落地后，剩下的都是「长期用得下去」的问题：单文件没有云端回收站，误删或换浏览器就全丢；分享卡是截图，改几个字也看不出来；4 个形象各画各的，提醒语 / 动画 / 进度容易走偏；剧情与结局散在脚本里。另外**上一轮 P0 留下一个真 bug**：点流水右侧的「×」是物理删除，删掉中间一笔会让哈希链 `seq` 断开，HUD 立刻标红「审计链断开」——明明是正常操作却报异常。

这轮全部收进一个「🗂 数据 / 凭证中心」弹层，四个 tab：**导入导出 / 复核凭证 / 传纸条 / 状态自检**。同样不新增生图与音频。

## 怎么做的

**① 删除改追加式 void**（修 P0 遗留 bug）：点「×」不再 `filter` 掉记录，而是 `appendLog(..., {type:'void', targetId})` 追加一笔撤销标记。`liveLogs(day)` 用 `voidIds()` 过滤掉 `void` 自身与被标记 id；`waterOf / milkOf / lastWaterTs / scoreDay / renderLogs` 全改走它。审计链只增不减，连续删两笔后仍 5 笔成链；被删的原始记录仍在导出镜像里，可人工核对。UI 上该行消失，HUD 不再误报断链。

**② 导入 / 导出 + 恢复向导**：`makeBackup()` 出 schema 2 镜像，带人类摘要、统计与 `checksum`（同步 FNV）；`parseBackup()` 先验 `app / schema / checksum`，被截断、改过字段、别的 app 一律拒绝。通过后才显示差异对比（档案 / 天数 / 流水 / 成绩 / 结局 / 照片），再给三选一：
- **合并（推荐）**：按 log id 去重、每日结算成绩取更高分、结局与 CG 取并集、设置保留当前偏好；导入的日志用 `appendLog` 按本机链重算，不破坏审计。
- **替换**：整体覆盖，先存 `dashui.pet.v1.undo` 快照。
- **新建档案**：把镜像第一个档案复制成新 profile，最多 8 个。

替换 / 新建都支持**5 分钟内撤销**。镜像含抓拍照片与在线模型 API Key，UI 用警示框写明「请自行保管、别随手发人」——这与 Toy 云档只放最小摘要形成明确分工。

**③ 离线复核凭证**：`DW-VOUCHER-1` 文本凭证带规则版本 `DW-R2`、13 项成绩摘要（分数 / 水量 / 有效打卡 / 拦截 / 奶茶 / 达标时刻 / 水合指数 / 审计链头 / 校验码）与校验和。分享卡面板新增「🔍 生成离线复核凭证」直达。接收方粘贴后跑 5 项检查：校验和自洽、校验码格式、关键字段完整、生成时间、以及一条**诚实声明**——「只证明按公开规则生成且内部自洽；接收方无对方流水，不能核验真实性」。不含照片、API Key、精确定位、天气、心情原文与完整语录。

**④ 离线传纸条**：`DW-NOTE-1` 只带 6 个字段（昵称 / 日期 / 一句话 / 生成时间 / 版本 / app）+ 校验和，另一台设备粘贴导入后桌宠 `say()` 朗读。不联网、不要账号，复制的是正向反馈而不是强竞争。

**⑤ CharacterDirector + 剧情表 + 深链**：`characterState()` 统一心情 / 进度 / 立绘 / 气泡 / 音频槽，`characterDirector(next,prev)` 返回 `unload / load / dataSignature`；`renderAll()` 包装后每次刷新过一次状态层。「状态自检」tab 逐一 setState 4 形象并比对业务数据签名（存档 / 当前档案 / 目标 / 券数），实测 4/4 完全一致。剧情沿用已有 `ST_ENDINGS` 六条 rank 表，新增 `storyDataAudit()` 校验 rank 唯一、条件可调用、CG keys 有效、运行时零 `eval`。深链支持 `?avatar=&mood=&view=story&voucher=&note=`，呼应仓库「搭配码 / 深链参数」的做法；也可从状态自检一键复制「形象+心情」或「直达剧场」链接。

## 验证

无头浏览器 **12 组用例全过，0 发现项、0 控制台错误**。覆盖：void 删除链不断且计算正确、连续删除、导出校验和与敏感内容、三类坏镜像拒绝、merge / replace / new 与撤销、中心四个 tab 渲染与导入预览三选一、凭证生成校验与篡改边界、接收方 5 项检查页、纸条字段与朗读、CharacterDirector 4 形象数据签名不变、剧情表自检、深链参数与直达剧场、分享卡凭证入口、P0 / Toy / 原有全链路回归（防作弊 / 双榜 / 音效默认关 / 剧场 / 设置 / 分享卡 / 刷新持久化）、375px 窄屏、体积与零外链 / 零 `eval`。

产物 **871.2 KiB**，增量 **26.0 KiB**（纯逻辑，无新增素材），61 张内嵌 WebP + 4 段 ogg 不变，零 CDN、零外部资源引用。

## 坑

1. **跨 script 段取值包装 = 启动全崩**（本轮头号问题）：P1 代码插在段 0，却写了 `const _setAvatarP1=setAvatar;`——`setAvatar` 定义在段 1，段 0 执行时还不存在，直接 ReferenceError，**导致段 0 后面的 `init()` 整段没执行**：启动渲染、定位、语录、提醒全没跑，控制台 13 次 `setAvatar is not defined`。改成不包装，一致性交给 `characterAudit()` 自检；并给回归补了 `scoreRendered / quoteRendered / auditMigrated` 断言，防止以后再漏掉「init 没跑」这类静默故障。
2. **`setTimeout(0)` 抢在后续 script 之前**：深链 `?view=story` 一开始没生效，但 `avatar` 参数生效了。根因是段 0 执行时剧场层（段 1）还没解析，`setTimeout(0)` 回调可能先跑，`typeof openStory==='undefined'` 被 `try/catch` 静默跳过。改成 `load` 事件 + 「`openStory` 未就绪就 50ms 重试，最多 12 次」。
3. **物理删除打断审计链**：P0 加了哈希链，但忘了改删除入口。用追加 `void` 而非 `filter` 解决，同时把所有读日志的入口收敛到 `liveLogs()`，避免漏改（漏一个就会出现「HUD 显示已删记录」或「积分仍计入被删的水」）。
4. **校验和不能防「整体重签」**：测试里把分数改成 99999 再重算 checksum，凭证仍显示「内部自洽」。这不是 bug，是设计边界——没有共享密钥就没法防重签，所以校验页第 5 条固定写明「不能核验真实性」，不把本机校验码包装成官方认证。
5. **替换 / 新建会丢当前状态**：直接 `S = 镜像` 会让用户回不去。加 `KEY+'.undo'` 快照 + 5 分钟窗口，并在三选一的说明里写清楚哪几个选项可撤销。
6. **凭证字段别贪多**：初版想带上语录与天气凑「信息量」，但那会牵出定位与心情原文。最后只保留 13 项成绩摘要，用「只查键名」的敏感词扫描做回归，确保照片 / Key / 经纬度 / 日志一个都不混进去。
7. **窄屏弹层**：数据中心四个 tab 在 375px 下要换行，给 `.dh-tabs button` 设 `min-width:68px` 与更小字号；modal 仍 `max-height:88vh; overflow-y:auto`，实测 0 横向溢出、按钮不越界。
8. **测试断言误报两处**：把 `card.hi / card.chain` 写在了 Node 侧而 `evaluate` 返回对象里没有这两个键；以及 `$(...)` 返回单个元素却当数组 `.find()`。都已改成在浏览器上下文里算好布尔值 / 用 `$$()`，并把「init 是否完整执行」补成硬断言。
