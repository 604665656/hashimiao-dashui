# 大水计算器 · 美术缺口与生图排期

> 目标：把「防作弊打卡 / 积分双榜 / 心情结算分享」这三套新机制，从纯 CSS+Canvas 排版升级为有哈士喵主视觉的完整美术层。
> 角色一致性：全部以 AVG 版内嵌的哈士喵现成立绘（`face/平静`，320×332 透明）为基准图做衍生，不重绘角色设定。

## 现状盘点（2026-11-11）

| 版本 | 现有美术 | 新机制的视觉现状 |
|---|---|---|
| 桌宠仪表盘版 | 0 张位图；水滴桌宠是内联 SVG，面板全靠 CSS | 打卡卡、排行榜、分享卡均无插画 |
| 哈士喵 AVG 版 | 26 张内嵌图：立绘 8 / 背景 10 / 情境 CG 8，另有 4 段音频 | 防作弊拦截复用「02_中性出题室」背景 + 「惊讶」立绘；结算/结局复用旧 CG；分享卡 `drawShareCard()` 是纯渐变+文字，`drawImage` 调用数为 **0** |

**结论缺口**：新增机制没有任何专属美术。现有 8 张 CG 都是「候机 / 新点子 / 空周末 / 做砸了」等原剧情情境，和「打卡、积分、拦截、颁奖」对不上。

## 全局约束（每轮都要遵守）

- 角色锚点：灰白猫、圆框眼镜、大水监察司监察本、1.5L 大水瓶；画风沿用现成素材的柔和日系治愈插画，米白 / 雾蓝 / 浅木色。
- 基准图：`_refs/hashimiao_base.png`（从成品 HTML 抽出的现成立绘）+ 可选 `_refs/hashimiao_bg.png`（主页书架氛围）。禁止链式参考，所有图直接参考同一基准图。
- **画面内不出现任何文字**：分数、日期、心情、校验码都由 Canvas 后期叠加，生成图只负责主视觉与留白。
- 构图：竖版素材主体偏下、上方约 1/3 留白；图标集为整齐网格、透明或纯浅底，便于裁切。
- 交付：每轮产出的 PNG 下载到沙箱，全部轮次完成后统一转 WebP 内嵌进两个单文件 HTML（保持「零 CDN、拷走就能玩」）。

## 每轮收尾动作

1. 下载 PNG 到沙箱并核对尺寸、透明通道。
2. 汇报「本轮完成，还剩 N 轮」。
3. 顺手跑一次 bug 巡检（两版浏览器冒烟 + 窄屏布局 + 控制台错误 + 关键链路断言），发现即修、修完复测。
4. 4 轮全部完成后统一内嵌接入，回归两版全链路。
